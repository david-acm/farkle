This file provides context and rules for agents working in this repository. HotDice is a .NET 10 sample application demonstrating Event Sourcing, CQRS, and vertical-slice architecture on the **Critter Stack** (Marten + Wolverine) with real-time multiplayer over SignalR.

## 2. Core Engineering Conventions

### Vertical Slice Anatomy
* **Feature folder:** Each use case lives in `src/HotDice/<FeatureName>/` containing:
  1. Command / Request contract
  2. Pure Decider: `Decide(...)` static function returning domain events or errors
  3. Wolverine.HTTP Endpoint: Bound with `[WriteAggregate(FromMethod = nameof(StreamId))]`
  4. Response mapping
* **No artificial layers:** Do not invent repository, mediator, or handler abstractions between endpoints and Marten/Wolverine. Embrace framework features directly.

### TDD & Testing Standards
1. **Red $\rightarrow$ Green:** Strict commit cadence. Red commit (failing test only) must precede Green commit (implementation).
2. **Test Tiers:**
   * **Domain Unit Tests** (`tests/HotDice.Tests/`): Fast, in-memory tests of pure deciders and aggregate evolution.
   * **Integration Tests** (`tests/HotDice.WebTests/`): Wolverine Alba scenarios against Testcontainers PostgreSQL/Marten.
   * **UI Component Tests** (`tests/HotDice.Ui.Tests/`): bUnit component tests.
   * **E2E Tests** (`tests/HotDice.E2ETests/`): Playwright browser tests.
3. **Build Integrity:**
   * Always compile with **warnings as errors** (`TreatWarningsAsErrors=true`).
   * Do not ignore or suppress compiler warnings.

### Code Generation & Contracts
* OpenAPI specification: `/openapi/v1.json` generated from ASP.NET Core OpenApi.
* Typed Client: Generated by **Microsoft Kiota** into `src/HotDice.ApiClient/`.
* Wolverine / Marten Codegen: Pre-generated code committed in `Internal/Generated`. If endpoints change, verify with JasperFx CLI.

### Autonomy Boundaries
**Stop and ask the user before:**
* Adding or modifying database schemas or migrations.
* Introducing new external dependencies or NuGet packages.
* Modifying public API contracts or security/JWT configurations.
* Performing destructive git or filesystem operations.
* Adding AI/bot attribution to commits or PR descriptions (work is human-authored).
