# Kiota Generated Client

This directory contains the HTTP client generated by [Microsoft Kiota](https://learn.microsoft.com/en-us/openapi/kiota/overview) from the OpenAPI spec at `UI/WebApp.Client/swagger.json`.

## Prerequisites

Install the Kiota CLI tool globally (one-time):

```bash
dotnet tool install Microsoft.OpenApi.Kiota --global
```

Then ensure the tools directory is on your PATH. On macOS/zsh:

```bash
export PATH="$PATH:$HOME/.dotnet/tools"
```

Add that line to `~/.zprofile` to make it permanent.

## Regenerating the client

Run this from the repo root whenever `swagger.json` changes:

```bash
kiota generate \
  -l CSharp \
  -d UI/WebApp.Client/swagger.json \
  -c FarkleApiClient \
  -n WebApp.Client.Services.Generated \
  -o UI/WebApp.Client/Services/Generated
```

| Flag | Value | Meaning |
|------|-------|---------|
| `-l` | `CSharp` | Target language |
| `-d` | path to spec | Input OpenAPI document |
| `-c` | `FarkleApiClient` | Generated client class name |
| `-n` | `WebApp.Client.Services.Generated` | Root namespace for generated code |
| `-o` | path to this directory | Output directory (will be overwritten) |

The `kiota-lock.json` file records the generation parameters so the same command can be re-run with just `kiota generate` (no flags) from this directory.

## How the client is wired up

`ClientServiceExtensions.cs` registers `FarkleApiClient` as a scoped service:

```csharp
services.AddScoped<FarkleApiClient>(sp =>
{
    var httpClient = sp.GetRequiredService<HttpClient>();
    var adapter    = new HttpClientRequestAdapter(new AnonymousAuthenticationProvider(), httpClient: httpClient);
    adapter.BaseUrl = httpClient.BaseAddress?.ToString().TrimEnd('/') ?? string.Empty;
    return new FarkleApiClient(adapter);
});
```

`GameService` receives `FarkleApiClient` by constructor injection and calls the fluent API:

```csharp
// POST /api/games/{gameId}/players/{playerId}/rolls
var response = await _client.Api.Games[gameId].Players[playerId].Rolls.PostAsync();
```

## NuGet packages

Six packages are required in `WebApp.Client.csproj` and `Farkle.SpaTests.csproj`:

```
Microsoft.Kiota.Abstractions
Microsoft.Kiota.Http.HttpClientLibrary
Microsoft.Kiota.Serialization.Json
Microsoft.Kiota.Serialization.Text
Microsoft.Kiota.Serialization.Form
Microsoft.Kiota.Serialization.Multipart
```

## Testing

Tests construct `FarkleApiClient` from a `MockHttpMessageHandler` via the `ToFarkleApiClient()` helper in `MockHttpClientBUnitHelpers`. Mock responses must use **camelCase** JSON property names to match Kiota's deserializer (handled automatically by `RespondJson`).
